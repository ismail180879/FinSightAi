SCHEMAS (models/schemas.py):

All previous schemas PLUS these new ones:

PredictRequest:
- asset: str
- asset_name: str
- category: str ("kripto" | "doviz" | "hisse")
- amount: float
- buy_price: float
- unit: str | None (e.g. "gram", "adet", "lot")

PredictionPeriod:
- price: float
- change_percent: float
- profit_loss: float
- is_profit: bool

PredictionChartPoint:
- label: str
- price: float

PredictResponse:
- asset: str
- asset_name: str
- amount: float
- buy_price: float
- current_price: float
- total_cost: float
- current_value: float
- current_profit_loss: float
- predictions: dict with keys:
    "1_hafta", "1_ay", "3_ay", "6_ay"
    each value is PredictionPeriod
- chart_data: list[PredictionChartPoint]
- analysis: str
- key_factors: list[str]
- risk_level: str ("DÜŞÜK" | "ORTA" | "YÜKSEK")
- disclaimer: str

async def get_gold_price() -> dict:
  GET https://api.metals.live/v1/spot
  Extract gold price (field: "gold")
  Also extract silver (field: "silver") 
  for silver asset.
  Return PriceResponse format.

async def get_metal_price(metal: str) -> dict:
  metal: "gold" | "silver"
  Reuse metals.live endpoint.

async def get_gold_history(days: int = 30) -> list:
  Generate mock history from current price.
  ±1.5% daily variation.
  Return [[timestamp_ms, price], ...]

SERVICE: services/forex.py

Use this FREE API (no key needed):
https://api.frankfurter.app

async def get_forex_rate(currency: str) -> dict:
  Map:
  "usd" → base="USD", target="TRY"
  "eur" → base="EUR", target="TRY"  
  "gbp" → base="GBP", target="TRY"
  
  GET https://api.frankfurter.app/latest
  Params: from={base}, to=TRY
  
  Extract rates.TRY as price.
  Return PriceResponse with:
  - symbol: currency.upper()
  - name: full name of currency in Turkish
  - price in TRY

async def get_forex_history(
    currency: str, days: int = 30) -> list:
  GET https://api.frankfurter.app/{start_date}..
  Params: from={base}, to=TRY
  start_date = today minus days
  Return [[timestamp_ms, price], ...]

ROUTER: routers/analysis.py

POST /api/analyze

Steps (same as before with category routing):

Step 1: Get price based on category + asset
Step 2: Get history based on category + asset
Step 3: Calculate technicals
Step 4: Get news
Step 5: asyncio.gather(
    analyze_news_sentiment(...),
    analyze_technicals(...)
)
Step 6: generate_recommendation(...)
Step 7: Return AnalysisResponse

ROUTER: routers/prediction.py  ← NEW

POST /api/predict
Body: PredictRequest

Steps:

Step 1: Get current price
  (same category routing as prices.py)

Step 2: Get price history (30 days)

Step 3: Extract close prices, 
  calculate technicals

Step 4: Get news articles (max 5)

Step 5: Call gemini.predict_asset(
    asset_name, category, current_price,
    buy_price, amount, unit,
    close_prices, news_articles, technicals
)

Step 6: Build PredictResponse:
  - total_cost = amount * buy_price
  - current_value = amount * current_price
  - current_profit_loss = current_value - total_cost
  - For each period: is_profit = profit_loss > 0
  - chart_data: build from current + 4 predictions
  - Fill all fields

Return PredictResponse
